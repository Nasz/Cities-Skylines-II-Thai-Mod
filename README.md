# Cities: Skylines II Thai Mod

Thai Localization Mod for Cities: Skylines II  
ม็อดภาษาไทยสำหรับเกม Cities: Skylines II

ดาวน์โหลดได้ที่ [Paradox Mods](https://mods.paradoxplaza.com/mods/79578/Windows)

ภาษาไทยโดยกลุ่มผู้เล่นเกม Cities: Skylines II

## การติดตั้งและใช้งาน

1. เปิดเกม Cities: Skylines II แล้วเข้าไปที่ [Paradox Mods](https://mods.paradoxplaza.com/mods/79578/Windows)
2. ค้นหา Thai Localization แล้วกด **เพิ่ม Mod ลงใน Playset**
3. ไปที่แท็บ Playset เพื่อตรวจสอบให้แน่ใจว่าม็อดถูกเปิดใช้งานแล้ว
4. **ออกจากเกมแล้วเข้าใหม่อีกครั้ง**

### หมายเหตุ
- Mod จะคัดลอกไฟล์ภาษาไทยไปยัง StreamingAssets โดยอัตโนมัติ
- ภาษาไทยจะถูกโหลดทุกครั้งที่เปิดเกม
- หากมีการอัปเดตภาษาใหม่ Mod จะอัปเดตไฟล์ให้อัตโนมัติ
